# JT Products Index

## Scope and mode

Primary: home product index. Mode: Experience. The projects and their real interfaces lead the first viewport; the site's structure recedes behind comparison and discovery.

Related: product detail pages. Mode: Persuade. These pages must make the project's purpose, evidence, and download action immediately intelligible.

## Audience, job, and action

Developers and technically comfortable users compare the maker's software, inspect real screenshots, and move to a release or repository. The primary action is opening the most relevant project and reaching a usable artifact.

## Proof and content

Use only existing product screenshots, names, feature descriptions, platform support, versions, releases, repository links, and local data statements from the project. Do not invent customers, benchmarks, or claims.

## Constraints

The site stays static Astro with native CSS. Future projects may use different media, so the global shell must remain platform-neutral. Maintain keyboard access, visible focus, readable contrast, responsive layouts, and existing release links.

## Direction contract

THESIS: JT is an independent product lab and index, not a desktop-app landing page. Refuse the warm-paper editorial shell and the generic SaaS hero with equal feature cards.

OWN-WORLD: Cool neutral ground, ink typography, electric-blue brand signals, product-specific accent colors, crisp one-pixel rules, restrained 8px geometry, and artifact-led previews. Desktop screenshots use a compact window bar; the system is ready for browser, phone, code, and image previews.

STORY: The visitor should understand within one scan that these are real, local-first projects made for daily use, compare what each project does, and move directly into the relevant project.

FIRST VIEWPORT: A compact studio sidebar establishes the maker and index. The main field begins immediately with project rows, each pairing a large real interface preview with type, version, status, one-line purpose, and a direct project link. On mobile the maker introduction becomes a short masthead and project rows stack without losing the artifact.

FORM: Pinned whole by the user's approval of the independent product lab plus index direction. seed: none (pinned) "独立产品实验室 + 索引能力；统一字体、间距、卡片和元数据，每个项目有自己的媒介预览。"

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
