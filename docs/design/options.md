# 四套可选 UI/UX 方向（基于 ui-ux-pro-max 设计库）

> 目的：现有蓝色 SaaS 版被否；先给可选方向，用户选定后再做整站效果图与 Astro 落地。

## 共同前提（四套都成立，不因选择而变）

- 内容源不变：`src/data/products.ts` 是唯一事实来源，三件产品（工作台 / 几件事 / 分支切换）真实字段照搬，不编造。
- 承诺不变：无账号、无后端、无统计；真实截图作证据；中文为主；直接务实、不写增长话术。
- 硬约束不变：键盘可达、可见焦点、`prefers-reduced-motion`、深浅两套对比度分别实测（正文 ≥4.5:1，次要 ≥3:1）、行宽 45–75 字符、触控目标 ≥44px、禁用 emoji 当图标（图标用手绘 SVG）。
- 不引入 UI 框架与依赖，继续原生 CSS + Astro 7 静态输出。

## 已有基线：E · 打样单（editorial-grid-magazine）

已交付的效果图与方案文档：`.impeccable/mocks/proof/shots/proof-home-1440.png`、`proof-ws-1440.png`、`docs/design/proof-sheet.md`。
它属于 `editorial-grid-magazine`（库内 rel 11.59）一类：冷中性纸底 `#edece6`、墨 `#15150f`、每项目左右版式不同（整版 / 文左图右 / 实墨整版）、Archivo + JetBrains Mono。可作为第五个选项，也可与上面的选项组合。

## 组合建议

- A + C：首页用 A 的网格，产品页用 C 的终端语义（安装命令、release 表）——适合三件都是工具站的现状。
- B + 打样单：B 的衬线与打样单的左右版式同源，取其一即可，不必叠加。
- D + A：D 的卡纸托框用于截图，A 的网格用于文字区——暖色只出现在图片周围。
