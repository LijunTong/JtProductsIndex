# 打样单 · 界面重构方案

> 方向名：**打样单（proof sheet）**。站点不再是"产品目录页"，而是一座把自己的软件当印刷品来打样的工作台：纸张、墨、规矩线、版次、样张。
> 本方案只做设计与效果图，未改动现有 Astro 源码。效果图见文末索引；打样用的 HTML/CSS 是本地草稿（`.impeccable/mocks/` 默认不进仓库），需要入库可以随时移出来。

---

## 1. 为什么换掉现在这一版

现在这版的问题是"模板感"来自结构，不是配色：

| 问题 | 现在的做法 | 打样单怎么做 |
| --- | --- | --- |
| 页面像 SaaS 落地页 | 左栏大标题 + 右栏项目行 + 三等功能卡 + 渐变蓝 | 一期一期排开的纸页，项目按"样张"编号与版次出现 |
| 三个项目看起来一样 | 每个项目同一套卡片骨架，只换强调色 | 三张样张三种版式：整幅出图 / 文左图右 / 整版实墨 |
| 截图只是插图 | 放在卡片里当配图 | 截图是主体，带裁切线、角标与样张说明，像印刷样张 |
| 信息密度低 | 大量留白 + 短句 + 图标 | 用表格、版次、文件名、体积、系统要求这类"真数据"承重 |

保留的东西：中文为主、直接务实、不吹不吹、真实截图、无账号无后端、深浅色、键盘可达。

## 2. 世界规则（五条，超了就不是这个方向）

1. **纸与墨二元**：只有 `paper` 与 `ink` 两族颜色，中间全部由透明度派生。强调色只用于焦点环、链接下划线、版权页的彩色墨条，不做大面积装饰。
2. **规矩线承重**：所有分隔用 1px / 2px 的发丝线，不用阴影、不用圆角卡片（产品截图自身圆角除外）。
3. **编号是地址，不是装饰**：`样张 01 / Work Station` 出现在左侧竖排栏，与内容一一对应；不用"01 02 03"当装饰序号（这条是硬规则，见 §8）。
4. **字体分两族**：Archivo（拉丁 + 数字，display 与正文）+ 系统中文字族回落；等宽 JetBrains Mono 只用于版次、文件名、体积这类机器数据。禁止用系统字体做 display，禁止单色等宽字体当装饰。
5. **一次编排过的动效**：首页三张样张进入视口时的"落纸"位移 + 淡入（`prefers-reduced-motion` 下关闭）；按钮 hover 位移 1px。其余一律即时。

## 3. 三个结构性决定

### 3.1 首页 = 一期打样单

顶部是刊头（JT 出品 / 打样单 2026.03 / 导航），下面立刻是**本期目录表**：编号、项目、形态、版次、状态。右边不是大按钮，而是一张像出版信息栏的表格——它顺手承担了"三件东西是什么/什么版本/能不能下"的全部问题。

然后是主标题 + 一句定位，接着三张样张：

- **样张 01 · 工作台**：整幅出图。标题栏（名称 + 拉丁名 + 定位句 + 右侧元数据：形态/版次/系统/状态）压一条 2px 粗线，下面是一张占满版心的截图，带裁切角标与样张说明。
- **样张 02 · 几件事**：文左图右。文字柱只占 1/3，元数据被推到与图注齐平的下缘——形成与 01 完全不同的阅读顺序。
- **样张 03 · 分支切换**：**整版实墨**。反转成墨底纸字，截图用浅色过版"裱"在墨上（`padding` + 背景色做卡纸边）。这是全页唯一的高对比段落，也是节奏的落点。

结尾是"为什么只有这几件"三栏说明（数据在本机 / 不需要账号 / 看得见的实现），再接版权页脚：印厂彩色墨条 + 打样日期 + 页数 + 技术栈。

### 3.2 产品页 = 一张单页样张的放大

- 报头（masthead）+ 细横条写明"桌面应用 · 可下载"与平台年份。
- **Hero**：6rem 级的项目名 + 拉丁名 + 定位句（26ch 断行）+ 摘要（54ch），右侧是元数据竖表（版次/形态/系统/运行时/存储/更新）。
- **下载表**贴在摘要下方，三行：名称 / 文件名·体积（等宽）/ 下载按钮。首行按钮是实墨填充，其余描边——不用等分卡片。
- **实墨数据带**：`4 列看板 / 3 档周期视图 / SQLite 单文件`，数大字压在墨色带上，全页对比最高的一处。
- **功能**：两栏、纯线条分隔的编辑式列表（不是六张卡）；首行 2px 粗线，"核心"用极小描边标签，不用图标网格。
- **界面**：截图组按 1 + 2 + 3 三种尺寸排，每张带样张说明；缩略图统一 `aspect-ratio` 裁到顶部对齐。
- **安装与数据**：三栏（运行要求 / 数据放在哪 / 技术栈），全部用真实文案。
- 页脚与首页同一套。

### 3.3 深色 = 同一张纸的夜景

不是"深色模式另做一套"，而是 `paper`/`ink` 两族整体对调，`field`/`on-field` 也跟着对调：

- 浅色：`paper #edece6`、`ink #15150f`、镶嵌的实墨块 `field #15150f`。
- 深色：`paper #121210`、`ink #eeece2`、实墨块反转为 `field #eae8dd`（在深色纸上一块浅色版）。

于是"整版实墨"在深色下变成"深色书里的白色插页"，逻辑一致，不需要第二套组件。

## 4. 设计令牌

```css
/* 纸 · 墨（浅色） */
--paper:    #edece6;   /* 页面纸色，偏暖，不是纯白 */
--paper-2:  #f6f5f0;   /* 抬升一层的区块（报头细条） */
--ink:      #15150f;   /* 正文与实墨块 */
--ink-2:    #46463c;   /* 次级正文 */
--ink-3:    #67665b;   /* 元数据标签（对比 4.89:1，通过 AA） */
--rule:      rgba(21,21,15,.30);
--rule-soft: rgba(21,21,15,.14);
--field:    #15150f;  --on-field: #edece6;   /* 实墨带 / 墨块 */

/* 深色 */
--paper: #121210; --paper-2: #1a1a17;
--ink: #eeece2; --ink-2: #c0beb1; --ink-3: #8f8d81;
--field: #eae8dd; --on-field: #121210;
```

焦点环 `--focus: #00718f`（浅色）/ `#62cde6`（深色）；彩色墨条 `#00718f / #b80058 / #8a6a00 / #15150f / #b6b5a9 / #6f6e63`，只出现在页脚 6 格。

字体：`Archivo`（400/500/600/700/800）承担 display 与正文数字；正文中文回落 `Noto Sans SC → PingFang SC → Microsoft YaHei`；机器数据用 `JetBrains Mono`。

尺度：容器 `min(1344px, 100% - 2×pad)`，`--pad: clamp(22px, 5vw, 72px)`；左侧竖排栏 `--rail: 46px`；display 用 `clamp(3.1rem, 8.4vw, 6rem)`、tracking `-0.045em`；正文 15–16px / 1.62–1.75；样张标题 `clamp(1.55rem, 2.75vw, 2.2rem)`。行宽：摘要 54ch、样张定位句 26–34ch、功能正文 44ch。

## 5. 状态与交互

| 表面 | 处理 |
| --- | --- |
| 悬停截图 | 边框转墨、图注左侧下划线外露，`→` 位移 2px |
| 按钮 | 实墨 ↔ 空心互换 + 1px 上浮，`180ms ease` |
| 焦点 | `:focus-visible` 2px 实线 + 3px offset，全站统一 |
| 选区 | `::selection` 墨底纸字 |
| 滚动条 | `scrollbar-color` 跟随主题（不上手写轨道） |
| 主题切换 | 报头右侧"夜班 / 白天"，写 `localStorage: jt-theme`，无闪白（`color-scheme` 同步） |
| 深色下的图片 | 不做反色、不做滤镜；截图原样，靠卡纸边与发丝线分隔 |
| 动效 | 仅"落纸"入场一处；`prefers-reduced-motion: reduce` 下全部即时 |
| 空态/边界 | 没有产品时目录表退化为一行说明；未上线版本状态用 `打样中` 印章 |

## 6. 无障碍与实测数值

对比度（WCAG 2.1，脚本实测）：

| 组合 | 比值 |
| --- | --- |
| 正文 ink / paper | 15.48 |
| 次级 ink-2 / paper | 8.06 |
| 元数据 ink-3 / paper | 4.89 ✅（已从 #6f6e63 的 4.34 调到 #67665b） |
| 墨带 on-field / field | 15.48 |
| 深色 正文 / 纸 | 15.84 |
| 深色 次级 / 纸 | 10.04 |
| 深色 元数据 / 纸 | 5.62 |

另外：语义地标（header/nav/main/footer + `dl` 数据表）、跳转链接、`lang="zh-CN"`、所有截图带中文 `alt`、表格带 `scope`、移动端 390 无横向滚动、竖排编号 `aria-hidden`（信息在正文重复一次）。

## 8. 硬红线（自检用）

- 不用 eyebrow / kicker 小标（"ABOUT / FEATURES"那种）。
- 不用 `01 02 03` 当装饰序号；编号只出现在样张编号与版次这类真实地址上。
- 不做等分卡片网格（六个功能不做六张同样大的卡）。
- 不用渐变文字、发光、彩色渐变背景。
- 图标只在必要处出现且为手绘 SVG（裁切角标、刊头十字准星、下载 `↗`）。
- display 不用系统字体；等宽字体不做装饰性排版。
