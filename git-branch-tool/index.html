分支切换Git Branch

换分支不用切回终端。

给 DeepSeek Harness 写的一个分支控件。输入框旁边放着分支图标和当前分支名，点开就能看到本地与远程分支、和上游的差距，直接切换或新建；工作目录还不是仓库时，同一个面板里就能初始化。

  1. 把这个仓库克隆到本机任意目录
  2. 在 Harness 的插件管理器里指向该目录安装（本地目录会被链接，不需要打包）
  3. 装好后在设置 → Git 分支里挑选控件位置
5个可放置的位置：输入框工具栏、会话标题旁等
5个分支动作：列出、切换、新建、初始化、删除
本机所有操作调用本机 git，不走网络

$cat features.md

# 围绕每天真正会用到的动作组织，不把功能堆成一张清单。

  • +分支控件核心

    输入框工具栏里一个分支图标、当前分支名和一个状态点：绿点表示工作区干净，黄点表示有未提交改动，灰点表示正在读取或当前目录不是仓库。

  • +切换分支

    本地分支排在前面，远程分支收起来并带数量；顶部有筛选框，当前分支标「当前」，行尾的 ↑N ↓N 是与上游的差距。点一下即切换，控件标签立刻刷新。

  • +新建分支

    面板底部是「分支名 + 起点 + 创建并切换」，起点下拉默认当前分支，填好名字回车就创建并切过去。

  • +非 Git 目录也能开始

    工作目录还不是仓库时，控件显示「非 Git 仓库」，面板里给一个按钮，就地执行 git init，不用先开终端。

  • +命令与工具进阶

    除了点界面，还能用 /branch list | switch | create | init 命令，或让对话里的 Agent 调用 git_branch 工具完成同样的事。

  • +位置随你放

    控件可以挂在 5 个位置之一，在设置里改；偏好存在浏览器 localStorage 里，不写配置文件。
