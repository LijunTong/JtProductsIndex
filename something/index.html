# 围绕每天真正会用到的动作组织，不把功能堆成一张清单。

  • +天气

    多城市切换、当前体感与湿度风速，再往后是未来几小时的逐时预报；结果缓存在本地。

  • +今日待办

    按截止时间排开今天的任务，标出优先级与逾期项；完成一项就少一项，数字当场更新。

  • +日程时间轴

    把当天的会议与约定按时间轴列出，每条可设提前提醒，到点由通知提醒你。

  • +邮件收件箱

    通过 IMAP 读取收件箱，按文件夹浏览、搜索并阅读正文；邮件缓存在本机，不经过第三方。

  • +番茄钟与信息流

    25 分钟专注计时配当日目标，旁边是订阅的信息流，工作间隙顺手扫一眼。

  • +Agent 接入（MCP）进阶

    开启后在本机 127.0.0.1 提供 MCP 服务，AI 助手可以把一份项目计划直接写成清单和子任务。
